# Contributing corrections

This repository accepts small, evidence-backed corrections to model status, access, and pricing records.

## What to include

- Link to a provider-owned product page, release note, pricing table, API reference, terms page, or app-store listing.
- Quote or describe the exact field that changed.
- Include the date you checked the source.
- Keep “web access,” “account access,” “API access,” and “pricing” as separate claims.

## What is not enough on its own

- A reseller or wrapper landing page.
- An unsourced social post.
- A demo video without an access or pricing statement.
- A search snippet without the underlying page.

Open one issue or pull request per correction so the evidence stays easy to review.
